Co-RL: Unsupervised Reasoning Emerges from Diverse Cohort in Multi-agent RL

01 / Method

The reward comes from a peer, never from yourself.

TTRL rewards a rollout for matching the policy's own majority vote. Intuitor rewards token-level confidence, RENT rewards low predictive entropy, and Co-rewarding-II rewards agreement with the vote of a slowly updated moving-average copy of the same weights. Every one of these signals is a function of the policy being updated. Without an external reference, the model is rewarded for being confident — not for being right — and training can drift toward homogenized responses, degeneration, or divergence.

STEP 01 Sample and vote

Each of N agents independently samples K completions for the same unlabeled prompt and reduces them to a self-consistency majority vote.

STEP 02 Reward against the peer

Agent n receives reward 1 when its extracted answer equals the majority vote of agent n−1, indices cyclic — so agent 1 is supervised by agent N. An agent never contributes to its own supervision target.

STEP 03 Independent GRPO step

Each policy normalizes rewards within its own rollout group and takes its own GRPO update. No shared parameters, no exchanged gradients.

â−n(x) ∈ argmaxb Σj=1..K 𝟙[ an−1j = b ]  — peer pseudo-label (ring)
rnk = 𝟙[ ank = â−n(x) ]  — indicator reward
maxθ JCo-RL(θ) = (1/N) Σn JGRPO(θn; {ynk, rnk})

The framework accepts any policy optimizer that takes sequence-level rewards; the paper uses GRPO and names REINFORCE++ as an alternative.

One training step, N agents
for each agent n = 1..N (in parallel, disjoint GPUs):
    sample K completions  y_n^1..y_n^K  ~  π_θn(·|x)      # same unlabeled prompt x
    a_n  ←  majority_vote( extract(y_n^1..y_n^K) )         # self-consistency vote
exchange votes                                             # the ONLY cross-agent step
for each agent n:
    r_n^k  ←  1[ extract(y_n^k) == a_(n−1) ]               # peer's vote is the target
    θ_n    ←  GRPO_update(θ_n, group-normalized r_n)       # independent optimizer state

"The agents share neither parameters nor gradients; their optimization is coupled solely through the rewards they provide to one another."

Self-rewarding · TTRL, Co-rewarding

The reward is computed from the model's own agreement with itself — its majority vote, a paraphrase, or a moving-average copy of the same weights.

Judge-based multi-agent · CoMAS

Agents debate in multi-turn interactions, and one of the system's own agents acts as an LLM judge that scores the exchange into a reward.

Co-RL

No judge, no learned reward model, no message passing. One exchanged vote per prompt, from an independently trained peer, along a directed ring.

RENT drives reward std → 0 with sharp increases in completion length Intuitor shows degenerate completion lengths on some models Co-RL holds stable reward variation and completion lengths at all four scales
Stated plainly TTRL is the most stable self-rewarding baseline in the training-dynamics figure and the strongest self-rewarding row on both 3B backbones — on Llama-3.2-3B-Instruct its 43.1 average even edges Co-RL (Same family) at 42.7. At 7B/8B, RENT (52.8 on Qwen2.5-7B) and Co-rewarding-II (46.6 on Llama-3.1-8B-Instruct) post the strongest self-rewarding averages. The failure of self-rewarding is degeneration or saturation, not universal collapse.
The pivot Separate parameters are enough to stop the degeneration — a same-family pair already trains stably. But a peer that fails on the same problems hands you back your own error: a same-family target largely repeats what the agent would have answered anyway. The question is not how to shape the reward. It is who is on the other end of it.

02 / Against the labeled reference

Trained without labels, measured against training with them.

Every Co-RL run on this page uses zero ground-truth labels. GT-Reward is the same GRPO recipe trained on the labels, under the same budget, included as a labeled reference. One chip per backbone-and-training-set block in the paper.

GT-Reward is GRPO with ground-truth rewards under this same recipe and budget — a labeled reference, not a bound on what supervised training can reach. Apart from AMC (avg@8, averaged over three evaluation seeds), every number is a single run evaluated single-sample; the paper attaches no variance to sub-point differences. Settings where Co-RL falls below the reference are never hidden (three in the default best-variant view; a fourth appears under Different family only). Vision-language chips marked MMR1 use the corrected multiple-choice grader and open-r1 chips the legacy grader, so the two are never compared with each other.

03 / The decoupling ladder

Five rungs of decoupling

"Diversity" on this page is not a vibe — it is an ordered, named, measurable axis. Each rung decouples one more thing between the two agents, and Co-RL's three published variants are positions on it. κ is Cohen's kappa over error patterns: lower means more decoupled errors.

04 / The probe

The ladder is measurable before you train — and it survives training

Base checkpoints, 500 MATH problems at levels 3–5, zero-shot, single sample at T = 0.8, rule-based extraction and equivalence checking. Every problem lands in one of four cells for a pair of models, and all four diversity measures are counts over those cells.

B correctB wrong
A correctboth correctonly A correct
A wrongonly B correctboth wrong

Complementarity c is the share where exactly one model is correct — the case where one model can correct the other. Wrong-agreement w is the part of the both-wrong cell where the two models return the same answer: the case a majority vote cannot detect. Cohen's κ measures how strongly the pair lands in the same cells beyond chance.

The finding Every different-family pair reaches κ ≤ 0.42 and c ≥ 29.4%. Every same-family and seed-only pair sits at κ ≥ 0.51 and c ≤ 24.6%. No pair falls between the two groups, at either tier. Averaged within groups, crossing families lowers κ from 0.53 to 0.38 and raises c from 23.2% to 30.8%. Same-family and seed-only pairs are not distinguishable from one another: changing the size, the generation, or the sampling seed within a lineage leaves the error structure where it was.
Scope κ and c are two readings of one four-cell measurement — across the twelve pairs they correlate at r = −0.98 — so they are not independent evidence; w is the genuinely additional reading. Twelve pairs, several sharing an anchor checkpoint; two different-family partners (Phi-3.5-mini, MiniCPM3-4B) never appear in a training run. The probe orders the rungs; it does not predict final accuracy quantitatively.

Group averages mix models of different strength, so here one model is held fixed and only its partner varies. Because the seed-only row is the anchor paired with itself, capability is identical along each ladder — the source of the partner is the only variable.

A same-family partner lowers κ by 0.04 and 0.07; a different-family partner lowers it by 0.18 and 0.16 while raising c by 9.2% and 10.4%. Wrong-agreement w points the same way and is lowest for the different-family partner under both anchors — but it does not order the middle rows, and the page says so out loud.

07 / Theory

Why a peer's vote can be worth more than your own

The paper reduces each prompt to two outcomes and tracks the probability p that an agent answers correctly, under GRPO dynamics. The same analysis that explains the gains also states exactly where they stop.

Under self-rewarding, the pseudo-label is constructed from the same rollout group being optimized — "making the update self-confirming: so the agent reinforces whichever answer is currently more likely, whether correct or not." Under Co-RL, the update magnitude qK(pA) is strictly positive, so agent A's update direction is set entirely by φK(pB) — the signed majority-vote direction of its peer. That is the formal content of "who your partner is".

ṗ_A = q_K(p_A) · φ_K(p_B),  ṗ_B = q_K(p_B) · φ_K(p_A)

For odd K, the expected self-rewarding update satisfies sign(GKself(p)) = sign(p − ½). So p(0) < ½ implies p(t) → 0 and p(0) > ½ implies p(t) → 1: self-rewarding cannot recover a prompt it starts out wrong on — it further suppresses the correct answer instead of correcting the error.

sign(G_K^self(p)) = sign(p − 1/2)  ⇒  p(0)<1/2 → p→0,  p(0)>1/2 → p→1

In the symmetric two-agent dynamics, the consensus states (1,1) and (0,0) are asymptotically stable, and (½,½) is a saddle whose interior separatrix is pA + pB = 1. The pair converges to the correct answer whenever pA(0) + pB(0) > 1 — strictly weaker than requiring both agents individually above ½.

B_self = { p_A > 1/2 ∧ p_B > 1/2 }  ⊊  B_Co-RL = { p_A + p_B > 1 }
Takeaway: Co-RL leverages complementary strengths to expand correct convergence. In the paper's worked example — (pA, pB) = (0.9, 0.2) on half the prompts and (0.2, 0.9) on the other half — each agent averages 0.55; self-rewarding converges to accuracy 0.5, Co-RL to 1.0, because pA + pB = 1.1 > 1 on every prompt.
Where it stops (0,0) is asymptotically stable too: a pair that starts below the separatrix converges together on the wrong answer. Co-RL widens the good basin — it does not remove the bad one. That failure mode is exactly what wrong-agreement w measures in the probe, and it is lowest for different-family pairs (1.8% for Qwen2.5-7B × Llama-3.1-8B) and highest for seed-only ones (5.2%). How the number, diversity, and interaction topology of agents shape cross-agent learning remains open; the directed ring is one topology among several.

08 / Run it

Pick your own rung

In the public release, the rungs are literally the launcher filenames. Apache-2.0, baselines included.

Repository map

  • llm/ — text experiments on MATH levels 3–5: trainers/co_rl/ (Co-RL), trainers/self_rewarding/ (TTRL, RENT, Intuitor), trainers/grpo/ (GT-Reward reference), eval/ (seven-benchmark suite).
  • mllm/ — vision-language experiments on open-r1 and MMR1, with the four-benchmark evaluation suite.
  • The baselines on this page ship with the method. tools/verify.py asserts the installed dependency versions match the paper runs.

The configuration behind the reported numbers

Optimizer
AdamW; rollout temperature 1.0
Text runs
lr 3e-6, effective batch 128 prompts per agent, 3072-token cap, K = 12, 2 epochs
Vision-language runs
lr 1e-6, 1024-token cap, K = 8, 1 epoch; token-level truncation of the importance-sampling ratio on Gemma-3 (measured log-probability drift ≈ 0.13)
Hardware
One node of eight H100 GPUs, four per agent
Text eval
T = 0.6, top-p 0.95; AMC avg@8 over three seeds; GPQA Diamond, boxed prompt; LiveCodeBench v6 official harness
Vision-language eval
Greedy, 16384-token budget, images long-side ≤ 1024 px; two-stage grader — the LLM judge only recovers rule-grading false negatives and never overturns a rule-credited answer
